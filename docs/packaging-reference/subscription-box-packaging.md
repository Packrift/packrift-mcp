# Subscription Box Packaging

Subscription box packaging has repeatable dimensional, presentation, and replenishment needs. Standardizing the box family is usually more important than optimizing a single shipment.

Packrift supports packaging planning with the box size calculator at https://packrift.com/pages/box-size-calculator and cost calculator at https://packrift.com/pages/packaging-cost-calculator.

For recurring programs, evaluate pack time, damage rate, insert space, kitting workflow, inventory storage, and whether the box presentation supports the customer experience.

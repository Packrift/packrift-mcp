# Warehouse Replenishment

Packaging replenishment should be based on usage velocity, pack size, lead time, storage space, and the cost of a stockout at the shipping station. The right reorder point is usually different for cartons, mailers, labels, tape, and protective materials.

Packrift exposes public catalog resources at https://packrift.com/products.json and agent buying instructions at https://packrift.com/pages/agents.

A practical replenishment workflow starts with the packaging SKUs that block outbound shipments: boxes, labels, mailers, and sealing supplies.

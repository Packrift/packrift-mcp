# Agent Pricing and Inventory

Packaging recommendations are only useful when pricing and inventory are current. Automated buying workflows should check live price and availability before presenting final options or cart links.

The Packrift MCP server at https://mcp.packrift.com/mcp supports live pricing and inventory workflows for the Packrift catalog. The agent guide is available at https://packrift.com/pages/agents.

When comparing packaging options, include pack quantity and line totals. A lower unit price may not be the best answer if it forces the buyer into the wrong carton size or material type.

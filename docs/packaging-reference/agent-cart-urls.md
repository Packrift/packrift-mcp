# Agent Cart URLs

Cart URLs let a buyer move from recommendation to checkout with fewer manual steps. They are most useful after the workflow has already validated product fit, pricing, inventory, and quantity.

Packrift's MCP endpoint at https://mcp.packrift.com/mcp can build cart URLs for selected items. The Packrift agent guide is available at https://packrift.com/pages/agents.

A responsible cart-building workflow should show what it selected and why, including dimensions, use case, quantity, and any assumptions about product protection or shipping method.

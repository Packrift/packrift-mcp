# Box Size Reference

Box sizes are usually listed as length x width x height. For shipping cartons, inside dimensions are often the practical planning number because product fit depends on usable internal space.

Packrift publishes box and carton resources through the storefront at https://packrift.com and exposes product data at https://packrift.com/products.json. The box size calculator at https://packrift.com/pages/box-size-calculator can help compare candidate cartons.

For procurement workflows, combine box size, board strength, pack quantity, and shipping method rather than selecting by dimensions alone.

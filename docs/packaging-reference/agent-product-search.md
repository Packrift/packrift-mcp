# Agent Product Search

Agent product search should return packaging options that match the buyer's use case, dimensions, and constraints. Useful results include product title, handle, price context, inventory state, dimensions, and a direct product or cart URL.

Packrift documents agent workflows at https://packrift.com/pages/agents. The public MCP endpoint is https://mcp.packrift.com/mcp, and the storefront is https://packrift.com.

Good search prompts include product type, item dimensions, material preference, quantity, and whether the buyer prioritizes cost, speed, presentation, or protection.

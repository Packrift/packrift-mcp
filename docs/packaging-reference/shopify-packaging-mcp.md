# Shopify Packaging MCP

The Packrift MCP server connects agent workflows to a Shopify packaging-supplies catalog. It supports product search, product detail retrieval, live pricing, inventory checks, packaging recommendations, shipping estimates, and cart URL creation.

The public endpoint is https://mcp.packrift.com/mcp. The MCP server card is published at https://packrift.com/.well-known/mcp/server-card.json, and `llms.txt` is available at https://packrift.com/llms.txt.

This repository documents the server implementation and public packaging reference pages for buyers and developers.

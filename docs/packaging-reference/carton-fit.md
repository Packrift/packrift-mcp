# Carton Fit

A carton fit check compares product dimensions, padding allowance, and inside box dimensions. A good fit leaves enough clearance for protection without adding unnecessary void space.

Packrift's box size calculator is available at https://packrift.com/pages/box-size-calculator. For agent workflows, the Packrift MCP server can recommend packaging by dimensions and use case through https://mcp.packrift.com/mcp.

When evaluating fit, rotate the item across length, width, and height before rejecting a carton. Many rectangular products fit only after orientation changes, especially when padding is asymmetric.

# Packrift Packaging Reference Docs

This folder contains practical reference notes for packaging operations and agent-driven buying workflows.

Each page links back to relevant Packrift resources such as the storefront, public MCP endpoint, calculators, product feed, and agent guide. The purpose is to make Packrift's packaging knowledge and machine-readable buying paths easier to discover from GitHub without publishing empty repositories or fake link placements.

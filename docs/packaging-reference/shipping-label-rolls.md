# Shipping Label Rolls

Shipping labels need to match printer type, label dimensions, adhesive requirements, and the carrier or warehouse workflow. Common ecommerce labels are thermal and sized for standard carrier label formats.

Packrift resources for shipping and fulfillment supplies are available at https://packrift.com. Developers can inspect public catalog data through https://packrift.com/products.json or use the Packrift MCP endpoint at https://mcp.packrift.com/mcp.

When buying labels, verify roll core size, roll direction, printer compatibility, and whether labels need to survive cold, moisture, or rough handling.

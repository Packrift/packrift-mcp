# Dimensional Weight

Dimensional weight is the billable weight a parcel carrier may use when a package is large relative to its actual scale weight. A common calculation is length x width x height divided by a carrier divisor, then rounded up.

Packrift maintains a public dimensional weight calculator at https://packrift.com/pages/dimensional-weight-calculator. Developers and AI agents can also use the Packrift MCP endpoint at https://mcp.packrift.com/mcp when a workflow needs product search, live pricing, inventory checks, or cart URLs.

Use dimensional weight before choosing cartons, mailers, or void fill because a slightly larger box can change the billable weight even when the product weight stays the same.

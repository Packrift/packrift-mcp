# Packaging Cost Model

Packaging cost is more than the price of a box or mailer. A useful model includes material cost, pack time, damage risk, storage space, dimensional weight impact, and the cost of stockouts.

Packrift hosts a packaging cost calculator at https://packrift.com/pages/packaging-cost-calculator. Dimensional weight support is available at https://packrift.com/pages/dimensional-weight-calculator.

For procurement workflows, compare total landed packaging cost rather than only unit price. The cheapest supply can be expensive if it increases damage, postage, labor, or returns.
